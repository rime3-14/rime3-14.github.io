# Rime's little nook

A small, responsive personal website made with HTML and CSS. No dependencies or build step.

## Preview

Run `node preview.mjs`, then open http://127.0.0.1:4173.

## Edit

- `index.html`: introduction, links, and page metadata.
- `styles.css`: colors, typography, and responsive layout.

## Publish with GitHub Pages

Create a public repository named `rime3-14.github.io` under the `rime3-14` account.
Push this website to its default branch. In the repository, open **Settings → Pages**,
choose **Deploy from a branch**, select that branch and **/ (root)**, and save.
The expected address is https://rime3-14.github.io/ once deployment completes.

Reference: https://docs.github.com/en/pages/quickstart
